# Custom keycaps

OpenSCAD-model voor een eigen keycap-profiel, met een complete set voor de
Sofle. Dit project is een modificatie van
[KeyV2](https://github.com/rsheldiii/KeyV2).

## Bestanden

- `profile.scad`: het profiel en de gedeelde instellingen
- `key.scad`: één losse toets
- `layouts/sofle.scad`: de volledige Sofle-set
- `src/`: de onderliggende code

## Gebruik

Open `key.scad` of `layouts/sofle.scad` in OpenSCAD, pas de waarden bovenin
aan, render met F6 en exporteer als STL.
